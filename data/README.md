# Logic data

These files are copied from alundra-randomizer at the release named in `randomizer.lock.json`. Do not edit them here. Change the randomizer, then copy the files again.

The current randomizer is https://github.com/Lunesar/alundra-randomizer. Copy each file from the path on the left onto the file on the right:

- `src/game/data/item.json` -> `item.json`
- `src/model/data/item_source.json` -> `item_source.json`
- `src/model/data/world_node.json` -> `world_node.json`
- `src/model/data/world_path.json` -> `world_path.json`
- `src/model/data/world_region.json` -> `world_region.json`
